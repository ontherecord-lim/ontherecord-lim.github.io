# 취준생 키우기

부모님과 함께 사는 집에서 21일 안에 첫 합격을 노리는 픽셀 육성 게임입니다.

## 플레이

`index.html`을 브라우저에서 엽니다. 호스팅용 원본에서는 `dist/index.html`을 엽니다. 같은 브라우저와 주소에서 캐릭터와 진행 기록이 자동 저장됩니다.

- 남성 또는 여성, 25세·26세·27세 중 하나를 고릅니다. 나이에 따라 첫 장면과 가족 대화가 달라집니다.
- 하루에 두 번 행동합니다. 지원서를 쓰거나 알바를 하고, 집밥과 낮잠으로 체력과 멘탈을 채울 수 있습니다.
- 동네 산책과 일상 선택은 픽셀 장면과 취준 일지에 반영됩니다.
- 방송기자, 취재기자, 콘텐츠 PD 공고에 지원할 수 있습니다. 공고와 채용 전형은 모두 가상입니다.
- 첫 플레이 동작 후 배경음악이 시작됩니다. 음표 버튼과 스피커 버튼으로 음악과 효과음을 각각 조절할 수 있습니다.

## 소스

| 파일 | 역할 |
| --- | --- |
| `index.html`, `style.css` | 캐릭터 선택과 반응형 화면 |
| `game.js` | 능력치, 일상 사건, 채용 규칙과 결말 |
| `app.js` | 상호작용과 브라우저 자동 저장 |
| `art.js` | 픽셀 캐릭터, 방, 공원과 아이콘 |
| `bgm.mp3` | 게임용 오리지널 칩튠 ‘지원서를 여는 밤’ |
| `scripts/compose-bgm.py` | 멜로디, 화음, 브라우저 재생용 음원 생성 |

배경음악은 이 게임을 위해 작성한 음표와 합성음으로 만들었습니다. 음원을 다시 만들려면 NumPy와 FFmpeg가 있는 상태에서 `python3 scripts/compose-bgm.py bgm.mp3`를 실행합니다.

하루 단위로 교육과 생활 활동을 고르는 구성은 [마법학교 아스티넬의 아기 펫 키우기 기록](https://www.readonly.wiki/w/%EB%A7%88%EB%B2%95%ED%95%99%EA%B5%90%20%EC%95%84%EC%8A%A4%ED%8B%B0%EB%84%AC)의 미니게임 항목을 참고했습니다.
