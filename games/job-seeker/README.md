# 취준생 키우기

부모님과 함께 사는 집에서 21일 안에 첫 합격을 준비하는 픽셀 육성 게임입니다.

## 플레이

`index.html`을 브라우저에서 엽니다. 같은 주소와 브라우저에서 캐릭터와 진행 기록을 이어 할 수 있습니다.

- 이름이나 닉네임, 남성 또는 여성, 25세·26세·27세 중 하나와 대학 전공을 골라 시작합니다. 먼저 취업한 동생과 집에서 지내며 가족과 친구를 만납니다.
- 하루에 두 번 행동합니다. 지원서·포트폴리오 준비부터 NCS, SQL, AI 답변 검증, 공정·품질·재고 실습까지 26가지 행동 중 선택할 수 있습니다.
- 7개 분야의 가상 채용 공고 25개에서 마감일, 고용 형태, 근무지, 하는 일, 추천 준비를 확인합니다. 관련 실습은 서류와 면접에 반영되고, 직무별 질문과 합격 장면이 이어집니다.
- 직접 관련 전공은 게임 내 서류 확률에 12%p, 면접에 6점을 더합니다. 인접 전공은 각각 6%p와 3점을 더합니다. 모든 공고에 지원할 수 있으며, 기존 캐릭터도 플레이 화면의 전공 선택에서 전공을 정할 수 있습니다.
- 가족과의 갈등과 화해, 친구의 취업·결혼, 동창회, 컨디션 변화 등에서 고른 답과 관계 점수에 따라 일부 장면이 달라집니다.
- 가까운 카페와 외곽 물류센터 중 알바를 고릅니다. 선택에 따라 수입과 경고가 달라지고, 물류센터에서 좋은 평가를 쌓으면 관련 공고에 추천받을 수 있습니다. 첫 알바와 합격은 가족 장면으로 이어집니다.
- 게임 속 생활비로 적금과 가상 주식을 고르고, 복권을 살지 결정합니다. 유튜브 채널을 열어 영상과 조회 수를 쌓거나 애니·게임·K팝을 취미로 고를 수 있습니다.
- 상단 음표와 스피커 버튼에서 게임용 칩튠과 효과음을 각각 조절합니다.

## 소스

| 파일 | 역할 |
| --- | --- |
| `index.html`, `style.css` | 캐릭터 선택과 반응형 화면 |
| `catalog.js` | 가상 채용 공고, 관련 실습과 면접 질문 |
| `story.js` | 가족·친구·일상 사건, 대사와 선택 |
| `game.js` | 상태 관리, 채용과 생활비 규칙, 결말 |
| `app.js` | 게임 화면과 브라우저 저장 |
| `art.js` | 픽셀 캐릭터와 배경 |
| `bgm.mp3` | 게임용 오리지널 칩튠 ‘지원서를 여는 밤’ |
| `scripts/compose-bgm.py` | 배경음악 음원 생성 |

음원을 다시 만들려면 NumPy와 FFmpeg가 있는 상태에서 `python3 scripts/compose-bgm.py bgm.mp3`를 실행합니다.
